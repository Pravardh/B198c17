# Installation

## Requirements

* Unity Hub
* Unity Editor **6000.5.6f1**
* Git
* macOS build available through GitHub Releases

## Installing the Unity Project

1. **Download Unity Hub**
   Download and install Unity Hub from the official [Unity website](https://unity.com/download).

2. **Open Unity Hub**
   Launch Unity Hub and navigate to the **Installs** tab.

3. **Install the Unity Editor**
   Select **Install Editor** and choose **Unity 6000.5.6f1**.
   If the version is not listed, it can be found in the [Unity Editor Download Archive](https://unity.com/releases/editor/archive).

4. **Clone the project repository**
   Clone the project from GitHub:

   [B198c17 GitHub Repository](https://github.com/Pravardh/B198c17)

5. **Add the project to Unity Hub**
   In Unity Hub, select **Add** or **Add project from disk**, then select the directory containing the cloned project.

6. **Open the project**
   Open the project using **Unity 6000.5.6f1**.

> **Note:** The project should be opened using Unity **6000.5.6f1** to ensure compatibility.

# Running the macOS Build

## Downloading the Build

1. Open the [The Executionist macOS Build release](https://github.com/Pravardh/B198c17/releases/tag/Build) on GitHub.

2. Under the **Assets** section, download:

   `TheExecutionistMacBuild.zip`

3. Once the download is complete, locate the ZIP file in your **Downloads** folder.

4. Double-click `TheExecutionistMacBuild.zip` to extract it.

5. Open the extracted folder. Inside, you will find:

   `TheExecutionist.app`

6. Double-click **TheExecutionist.app** to launch the game.

## macOS Security Warning

Depending on the macOS security settings, macOS may prevent the application from opening because it was downloaded from the internet.

If this happens:

1. Try opening `TheExecutionist.app` once.
2. Open **System Settings**.
3. Navigate to **Privacy & Security**.
4. Scroll down to the **Security** section.
5. If the application was blocked, select **Open Anyway**.
6. Confirm by selecting **Open**.

> **Note:** Make sure to extract the ZIP file before launching the application. Do not attempt to run the application directly from inside the ZIP archive.

# Game Controls

| Input                 | Action        |
| --------------------- | ------------- |
| **W**                 | Move Forward  |
| **A**                 | Move Left     |
| **S**                 | Move Backward |
| **D**                 | Move Right    |
| **Left Shift**        | Sprint        |
| **Left Mouse Button** | Attack        |

### Movement

Use **WASD** to move the character:

* **W** — Move forward
* **A** — Move left
* **S** — Move backward
* **D** — Move right

### Sprint

Hold **Left Shift** while moving to **sprint**.

### Attack

Press the **Left Mouse Button** to perform an **attack**.
